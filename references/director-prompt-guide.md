# 导演版提示词写法与「内容单薄时如何丰富」

写给逐镜「画面提示词」与「声音提示词」的指南。目标：提示词读起来有镜头感，能直接喂给 Seedance / 即梦并得到稳定、连贯、风格统一的画面。

## 一、画面提示词七要素（每镜尽量写全）

1. **主体与动作**：谁，在做什么，动作的顺序与结果（先…后…）。动作要具体可拍，不写抽象情绪名词。
2. **景别与构图**：特写/近景/中景/全景/主观镜头；构图方式（中心/对角线/双人/纵深/群像/动感/前后景对比/圆形遮罩）。构图要服务信息：双人对话用双人构图，孤独感用前后景虚实对比，速度感用动感构图。
3. **光线**：光源方向（侧光/顶光/屏幕光/聚光灯）+ 色温（如钨丝灯暖光 2800K vs 屏幕冷白光 6500K）+ 光比（一半暖光一半阴影）。光线呼应情绪：冷调=疏离/压抑，暖调=温馨/狂热，冷暖对比=身份与关系的反差。
4. **色彩基调**：本镜主色（冷灰蓝、暖棕、霓虹色、冷白），用于区分现实与回忆（回忆常用暖黄柔焦）。
5. **景深与焦点**：浅景深虚化背景成光斑，或前后景虚实对比，明确焦点落在谁脸上/什么物件上。
6. **材质与细节**：皮肤质感、睫毛发丝、布料飘动、金属反光、屏幕冷光倒影、水雾/光晕/粒子。材质细节让 CG 渲染真实。
7. **微表情与身体语言**：瞳孔收缩、眉头轻皱、嘴角下压、指节泛白、屏息、肩膀线条。用身体反应代替"她很伤心"。

## 二、运镜语言（写清动机）

- 固定 = 让观众注视情绪/信息；缓慢推入 = 逼近内心/强调；缓慢拉出 = 抽离/孤独；摇摄 = 建立关系与空间；跟拍 = 紧迫与穿行；手持呼吸感 = 不安/纪实感；POV 圆形遮罩 = 望远镜/主观窥视，配轻微晃动；叠化 = 时间跳跃/回忆；快速剪辑 = 闪回堆叠；定格 = 悬念收尾。
- 每镜运镜都写一句「为什么」：例如"镜头缓慢推进到他的面部"（从群体中逼近个体情绪）。

## 三、声音设计（每镜必写）

- 拟声词写实：嗡——（震动）、嘟——（忙音/拨号）、吱——（轮胎摩擦）、咔嗒（按键）、叮（消息）、叮铃铃（铃声）、金属机械声（望远镜）。
- 环境层次：写清远近与变化——由远及近、渐弱、戛然而止、空旷回声、背景声衬前景。
- 情绪音：心跳声、屏息气声、压抑的深呼吸、脚步声停止、环境声渐弱至静。

## 四、内容单薄时如何丰富（分镜表只有一句话/缺画面描述时）

原则：**只补表演、光线、声音、转场、道具与情绪细节，不改剧情、不加角色、不改台词原文。**

1. **从剧情因果补表演**：根据前后镜头的剧情推角色的即时反应。例：接到坏消息→瞳孔收缩、眉头皱紧、指尖悬停迟疑、握手机的手微微颤抖；看到难以接受的真相→指节泛白、胸口起伏、眼眶微红。
2. **用光线表达关系**：把人物关系画成光——亲密=暖光笼罩，疏离=冷调侧光/一半阴影，受制于人=冷白屏幕光打脸，被冷落=处于画面边缘且光线黯淡。
3. **补转场与衔接**：场景/时间跳跃用叠化+柔焦（回忆）或声音先入（画外音先到，画面后切）；情绪急转用"环境声渐弱→心跳声浮起"。
4. **补群像与道具细节**：人群=涌动、剪影、虚化光斑、齐声呐喊由远及近；手幅/旗帜=布料飘动、印字清晰；手机=屏幕发光、显示具体界面；赛车=速度线、动态模糊、轮胎火花、引擎粒子。
5. **情绪链推进**：每组素材明确"观众看完这组镜头，情绪从 A 变成 B"（如从悬念→震惊→苦涩→孤独→坚定），逐镜分配情绪增量，不让镜头重复同一个情绪。
6. **统一风格兜底**：分镜表没有写风格时，默认 3D CG动画、电影级写实渲染、8K高清、16:9横屏；夜晚场景默认给色温对比（暖环境光 vs 冷屏幕/冷白灯），回忆默认暖黄柔焦。

## 五、禁止项

- 不改写台词、旁白、广播原文（逐字保留）；无台词写（无）。
- 不新增角色、不改变剧情走向、不编造人物设定；只能用合理的表演/环境/声音细节填充。
- 不把不同镜头的人物外形写矛盾（同一角色外形气质全片一致）。
- 不确定的内容（如具体地名、身份）不编造；无法确定时用"某人/某处"并在交付说明中注明。
