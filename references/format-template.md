# 飞书文档格式模板（Seedance 提示词文档）

交付物为飞书在线文档（docx），不是表格。创建时按 lark-doc 技能的 Authoring 流程：init-draft → 写 XML → parse 检查 → +create → fetch 回读验证 → present_files 交付链接。

## 文档总结构

```
<title>《片名》提示词（Seedance 详细版）</title>
<p>总览段：共 N 组视频素材、M 个镜头，总时长 T 秒；全片统一风格（3D CG动画、电影级写实渲染、8K高清、16:9横屏）；可直接逐镜复制到 Seedance / 即梦使用。</p>
<h3>视频素材 1：名称</h3>
<ul>
  <li>对应场次：1-1 地点 夜 内/外</li>
  <li>核心情绪：一句话概括本组让观众感受到的情绪变化</li>
</ul>
<p>统一风格：本组的光线基调（色温对比）、色彩、氛围、景深与构图语言……</p>
<p>角色：角色A、角色B、（电话音/回忆虚影）……</p>
<p>场景：具体地点 夜 内/外</p>
<p>[Shot_no:1.1 3秒 | 景别 | 构图 | 背景：… | 运镜：… | 画面提示词：… | 台词：… | 声音提示词：…]</p>
<p>（每镜一个段落，后续镜头同理）</p>
<h3>视频素材 2：名称</h3>
……（重复组结构）
```

## 分组规则

- 按场景/地点变化把全部镜头分成若干「视频素材」组（示例：家中来电→赛场外→观众区→VIP看台→散场→走廊），每组 2–15 镜。
- 组名用「核心事件」命名（如：深夜来电、望远镜里的真相、走廊重逢），不用流水号。
- 每组头部必须写全：对应场次、核心情绪、统一风格、角色、场景。

## 逐镜行格式（严格固定）

```
[Shot_no:X.Y 时长 | 景别（ECU/CU/MS/LS/POV）| 构图 | 背景：… | 运镜：… | 画面提示词：… | 台词：… | 声音提示词：…]
```

- X = 素材组序号，Y = 组内镜头序号（如 4.3 = 素材4第3镜）。
- 景别标注：特写（ECU）、近景（CU）、中景（MS）、全景（LS）、主观镜头（POV）、闪回片段。
- 构图常用词：中心构图、对角线构图、双人构图、纵深构图、群像构图、动感构图、前后景对比构图、圆形遮罩。
- 台词：`【角色名】“原文”`；内心独白写 `角色名（内心）：“……”`；旁白/广播/画外写 `旁白（画外音）` / `广播` / `画外`；无台词写 `（无）`。
- 声音提示词：写实拟声（嗡——、嘟——、吱——、咔嗒、叮）与环境层次（由远及近、渐弱、空旷回声、心跳/屏息）。

## XML 要点

- `<title>` 开头；每组视频素材用 `<h3>`；组内头部信息用 `<ul><li>`；每镜一个 `<p>`。
- 中文引号“ ”直接写，无需转义；如内容含 `&`、`<`、`>` 需按 XML 规则转义（`&amp;`、`&lt;`、`&gt;`）。
- 每镜段落只放一条提示词，段间不空行由渲染器处理。
- 创建后必须 fetch 回读核对首镜、末镜与标题存在；交付用 present_files，最终回复 ≤300 字、≤8 行。
